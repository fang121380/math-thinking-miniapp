# 初中数学扩展设计

## 目标

在不破坏已有小学学习记录和题库的前提下，为梵数学增加初一、初二、初三的学习入口、8 个教材版本的独立题库、摸底、自主练习、错题分析和适龄思维游戏。

## 范围

- 学段：小学（1-6 年级）与初中（7-9 年级）。
- 初中教材：人教版、北师大版、苏科版、沪科版、鲁教版、湘教版、华师大版、浙教版。
- 每个教材与年级组合都有独立的知识点地图、题目模板、题干措辞和重点方向。
- 每个组合均覆盖简单、适中、困难三档，以及选择题、填空题、大题三种题型。
- 每题都有标准答案、分步解析、知识点总结、易错点、原创考法标签和自动审计元数据。

## 课程与选择流程

1. 首次进入或本次升级后，学生先选择“小学”或“初中”，再选择具体年级。
2. 教材默认人教版，可在“我的”页面切换；切换教材、学段或年级仅清空正在进行的任务，不删除历史答题、错题和成长记录。
3. 初中学生完成对应年级、当前教材的 5 道轻量摸底题后，进入每日练习。
4. 每日练习、自主练习、错题重练和游戏只从当前学段、年级、教材的题库中取题。

## 初中知识范围

| 年级 | 核心知识 | 思维考法 |
| --- | --- | --- |
| 初一 | 有理数、整式、一次方程、线与角、三角形初步、统计 | 符号与数轴、去括号、逆向列方程、分类讨论、读图与数据判断 |
| 初二 | 全等三角形、轴对称、一次函数、分式、勾股定理、数据分析 | 几何条件链、函数图像、变量关系、方程与函数联动、实验数据解释 |
| 初三 | 二次函数、圆、相似、锐角三角函数、概率、综合应用 | 图像与最值、几何证明链、相似建模、分类讨论、方案比较与估算检验 |

## 题库架构

题目新增 `schoolStage`（`primary` 或 `junior`）字段，年级使用实际数字 1-9。初中教材使用独立 ID（例如 `jr-rjb`、`jr-bsd`），避免与小学同名教材的历史记录和题目混淆。题库选择器必须同时按教材、学段、年级、难度、题型、知识点筛选；同一次学习任务中不得重复题目 ID、题干或计算结构。

初中题库不直接转载试卷。公开真题和模拟题只用于提炼考法、难度梯度和常见易错点；最终题干、数字、情境、选项和解析均为本地原创内容。每题保留 `sourceRegion`、`sourceYear`、`examPattern`、`reviewStatus`、`reviewedAt` 元数据，明确为考法参考而非原题来源。

## 质量与安全规则

- 数量题保存 `answerUnit`；正确单位可填写，错误单位不可判对；无量纲纯算式不强制单位。
- 选择题必须只有一个可判对选项；填空与大题答案必须与计算表达式、单位和解析一致。
- 几何、函数、方程题必须校验题干条件完整，例如图形边长、变量定义、取值范围和问题目标。
- 每个教材 x 年级 x 难度 x 题型至少有 24 道题、8 个知识点、多个不同考法；不足时构建失败。初中题库按当前教材、学段和年级按需生成并缓存，不能在小程序启动时构建全部初中范围。
- 摸底题为 5 道代表性轻量题，覆盖运算、概念、建模、图像/几何和数据/推理，不以大计算量作为筛选方式。
- 游戏按学段筛选：初中增加方程闯关、函数图像配对、几何条件侦探、代数规律与概率策略；每轮必须可解、答案唯一、提示与规则一致。

## 数据兼容与更新

- 现有小学进度保持可读；缺失 `schoolStage` 的旧记录按小学处理。
- 存储版本升级后，所有用户被要求确认一次学段与年级，但不删除历史记录。
- 内容版本更新后只更新当天任务和内容提示，已完成记录与错题记录保留。
- 初中题库暂随安装包离线发布；远程内容包协议继续保留本地回退，未配置云端时不请求外部服务。

## 验收标准

1. 小学 1-6 与初中 7-9 可从两个层级的选择器中正确选择并持久化。
2. 8 个初中教材 x 3 个年级均可生成 5 道摸底、每日题和专项练习，且不与其它组合混用。
3. 每题通过答案、单位、选项、解析、条件完整性和重复度审计。
4. 初中题库、游戏和错题本不会让小学用户看到初中内容，反之亦然。
5. 全套自动测试、包体检查和微信开发者工具编译通过；不增加未经授权的网络服务、个人信息采集或商业题库内容。
