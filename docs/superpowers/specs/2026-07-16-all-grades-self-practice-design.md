# 全年级题库与自主练习设计

## 目标

将“梵数学”从仅支持四年级的人教版本地题库，扩展为覆盖小学一至六年级上下册的原创题库。学生完成每日任务后，可以按专题、题型、难度和题量继续自主练习；每道题和每条错题记录均提供知识点总结、易错点总结与分步解析。

## 范围

- 教材范围：人教版小学数学一至六年级，上下册。
- 题库来源：仅使用项目原创、本地维护的题目；不导入未授权或不可审校的第三方题库。
- 题型：选择题、填空题、应用大题。
- 难度：1 为简单，2 为适中，3 为困难；同一知识点的变式按由简单到综合排序。
- 每个年级保留 8 个摸底槽位，每槽位至少 4 道变式，合计至少 32 道摸底题。
- 每个年级的每日练习题至少 48 道，选择、填空、应用大题各至少 16 道；四年级保留现有 84 道练习题并继续扩充。
- 所有题干在整个已发布题库中唯一；每日、摸底、错题重练三种抽题不允许抽到同一题干。

## 年级内容地图

| 年级 | 上册重点 | 下册重点 |
| --- | --- | --- |
| 一年级 | 20 以内数与加减、位置、图形、钟表 | 100 以内数与加减、人民币、分类与规律 |
| 二年级 | 100 以内加减、表内乘法、长度、观察物体 | 表内除法、万以内数、时间、统计 |
| 三年级 | 乘除法、分数初步、长方形和正方形、质量 | 两位数乘法、面积、小数初步、数据整理 |
| 四年级 | 大数、三位数乘两位数、除法、角与图形 | 四则运算、平均数、小数、观察与优化 |
| 五年级 | 小数乘除、因数倍数、图形与面积 | 分数、体积、统计、实际问题 |
| 六年级 | 分数乘除、比、圆、百分数 | 比例、负数、圆柱圆锥、统计与综合应用 |

## 题目数据契约

每题必须拥有既有字段 `grade`、`term`、`unit`、`knowledgePoint`、`ability`、`type`、`difficulty`、`prompt`、`answer`、`hint`、`solution.steps` 和 `commonMistakes`，并新增：

- `knowledgeSummary`：一句儿童可理解的知识点总结，说明本题要掌握的规则或方法。
- `mistakeSummary`：至少一条儿童可理解的易错提醒，明确容易错在哪里和怎样避免。

答对后显示“知识点总结”和“易错提醒”；答错后在原有解析之外显示“这次为什么会错”、知识点总结、易错提醒和同知识点同题型的不同重练题。

## 自主练习

新增“自主练习”选择页。学生从首页每日任务完成区或“我的”页进入，选择：

- 当前年级内的一个知识专题，或“全部专题”。
- 选择题、填空题、应用大题，或“全部题型”。
- 简单、适中、困难。
- 3、5 或 10 题。

抽题优先级：符合筛选条件且未完成的题 -> 已完成的同筛选题 -> 同专题错题复习。题库耗尽时不显示空白页，显示“本专题新题已完成，开始复习已做题”，并继续提供可作答的复习集。

自主练习写入能力和错题记录，但不修改当天的每日任务完成状态、每日题目列表或每日进度。

## 架构

- 按年级拆分本地题目模块，避免单一题库文件持续膨胀；统一由题库入口聚合。
- 题目创建器接收年级参数，禁止继续隐式固定为四年级。
- 设置页开放一至六年级选项；题库清单记录全部启用年级及每年级的摸底、练习题数量。
- 摸底选题与每日选题均按当前设置的年级过滤。
- 自主练习使用独立的筛选与抽题入口，生成临时练习集，不复用每日题集存储键。

## 错误处理

- 筛选条件没有题目时，给出“该专题题库正在建设中”的提示和返回专题选择入口。
- 题目数据缺少答案、解析、知识点总结或易错点总结时，在构建期测试中失败，不进入发布题库。
- 重练题找不到同知识点同题型的不同题目时，退回同题型的未完成题，并保留说明。

## 验收与测试

- 所有年级都可在设置页选择，并且每日题与摸底题只来自选中年级。
- 每个年级均同时具备选择、填空、应用大题及三个难度级别。
- 所有题干全局唯一；每题具备答案、分步详解、知识点总结和易错点总结。
- 自主练习严格遵守年级、专题、题型、难度和题量筛选，优先返回未完成题。
- 自主练习完成后不改变每日任务进度；错题记录包含可读的知识点和易错点总结，并可进入不同题目的重练。
