# Random Thinking Games And Answer Equivalence Design

## Goal

Replace the placeholder game area with three complete, locally generated thinking games and prevent correct mathematical expressions from being marked wrong because of harmless formatting differences.

## Confirmed Problems

- Only the Number Puzzle row has a tap handler; Pattern Detective and Shape Partition are static rows.
- Every game entry navigates to the same page without a game type.
- The Number Puzzle has one hard-coded board, fixed `第 2 关` copy, and starts one move from completion.
- Answer checking removes ordinary whitespace but does not canonicalize full-width punctuation, invisible spaces, or equivalent division/multiplication symbols.
- Previous preview verification did not play each game flow end to end.

## Game Model

The first release remains local-only. It has three game types:

1. `puzzle`: a solvable 3x3 sliding puzzle generated by applying legal non-reversing moves to the solved state. Scramble depth increases with difficulty.
2. `pattern`: a generated sequence puzzle using arithmetic, geometric, increasing-difference, alternating-operation, and interleaved templates. Each round has four unique answer choices.
3. `partition`: a connected-cell shape transformed by rotation/reflection. The learner selects exactly half the cells so both selected and unselected halves remain connected.

There are no fixed visible level numbers. Each game displays `随机挑战` plus its current difficulty. Difficulty is derived from completed rounds: 0-2 easy, 3-6 medium, and 7 or more hard.

## Randomness And Repetition

- Generators accept an injected random function so behavior is deterministic in tests.
- Every challenge has a content signature.
- The last 10 signatures per game type are persisted and excluded from generation.
- An unfinished challenge is persisted and resumed exactly.
- Completing a challenge clears the active round and `再来一局` generates a different challenge.
- The daily recommendation is selected from learner ID and date, so it changes across days and is not always Number Puzzle.

## Progress And Rewards

- Persist active challenges, completion counts, recent signatures, and rewarded challenge IDs locally.
- Award one thinking star only once per challenge ID.
- Cap rewarded IDs to the newest 100 records.
- Reset, hint, back, next-round, and repeated-completion paths must not duplicate rewards.

## Answer Equivalence

Create a shared answer utility used by both diagnostic and daily practice pages.

- Apply Unicode NFKC normalization.
- Remove ordinary, non-breaking, ideographic, zero-width, and BOM spacing.
- Normalize full-width parentheses and punctuation.
- Treat `÷`, `/`, `:`, and `：` as division.
- Treat `×`, `*`, `x`, and `X` as multiplication when used in a mathematical expression.
- Normalize Unicode minus variants to `-`.
- Preserve expression structure; do not accept a numerical result when the prompt asks for a formula.

The screenshot regression `(48+12) ÷6` versus `(48+12)÷6` must pass.

## User Interface

- Every game row is tappable and sends a game type to the shared game page.
- The hub shows each game's completion count and a date-based recommendation.
- The game page renders one of three complete modes with the same compact header, feedback band, reset/hint controls, and next-round action.
- All boards use stable dimensions and practical touch targets without overlapping the cutout or system capsule.

## Verification

- Pure tests cover generator validity, solvability, uniqueness, connectivity, difficulty, persistence, one-time rewards, and expression equivalence.
- Full project checks cover JavaScript, JSON, WXML bindings, assets, and secrets.
- In WeChat DevTools, personally operate every control and complete multiple random rounds of all three games, including reset, hint, wrong action, completion, next round, back/resume, recommendation, and no duplicate reward.

## Activity feedback, audio, and reminder amendment

- Every activity failure uses a short child-facing message that identifies the next action: retry load, retry save, tap again, choose an answer, adjust the selected cells, or restart the round.
- Answer feedback uses three original local WAV tones for correct, wrong, and completed states. The setting is persisted and asynchronous audio failures remain non-blocking.
- Learning reminders are local and honest about the platform boundary: when enabled, Home shows one reminder on the first open of a day with no completed work. Background WeChat subscription messages remain out of scope until a reviewed template and user authorization exist.

## Out Of Scope

- Network game service, multiplayer, rankings, ads, timers, purchases, and student identity collection.
