# 首次年级确认与五题摸底设计

## 目标

首次打开梵数学时，先让孩子选择当前年级，教材固定为人教版；随后用五道低计算量、代表性强的题目建立初始学习画像。

## 用户流程

1. 从未确认过年级的新用户进入引导页，看到六个年级按钮和“人教版”说明。
2. 选择年级后，保存年级和首次确认标记，再进入五题摸底。
3. 五题完成后显示“初步了解”，后续每日练习继续修正掌握状态。
4. 已完成或正在进行摸底的用户不重新触发年级选择；教材和年级仍可在“我的”页修改，修改后会按现有逻辑重新摸底。

## 五题蓝图

每个年级、每个教材题库都从五个独立知识点选题，按稳定顺序展示：数感/估算、基础关系判断、图形或空间观察、规律或数据阅读、生活应用策略。题目以选择为主，含一题简短填空和一题轻量应用；不选择多位数长算式或多步骤大计算。

题目采用教材常见考法的原创改写，保留答案、提示、分步解析、知识点和易错点。五题的结果只作为初始推荐，不能宣称完整评估。

## 数据与兼容

进度新增 `initialGradeConfirmed`。空白本地进度为 `false`；存在历史学习、已完成摸底或未完成摸底的旧进度自动视为已确认，防止更新后强制重置。首次选年级通过现有 `changeGrade` 重置学习画像，但保留用户的长期学习记录。

## 验收

- 新进度必须先选 1-6 年级才可进入摸底。
- 默认教材为人教版，选择年级后摸底题全部属于该年级的人教版。
- 每次摸底恰好五题，五题知识点、题目 ID 均不重复，覆盖四类能力和选择/填空/应用题。
- 变式随重测轮换；进行中的五题可以恢复。
- 旧进度不被强制打断；所有自动化测试、包体预算与开发者工具编译通过。
