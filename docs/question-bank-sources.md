# 题库参考与更新规则

## 参考范围

1. 教育部《义务教育数学课程标准（2022年版）》：确定小学数学核心素养、学段目标和内容范围。
2. 人教版、北师大版、苏教版、青岛版、上海版、西师大版、冀教版、湘教版公开教材目录：确定各版本的单元顺序、教学侧重和常用情境。
3. 全国各地公开真题与模拟题：只提取题型结构、常见设问、易错方式和难度梯度，不复制整题或整套试卷。
4. 山东济宁、曲阜公开教材使用信息：默认学习路径优先贴合当地常见的人教版内容。

## 原创改写要求

- 更换数值、人物、地点、物品和问题目标。
- 重新设计干扰选项，不沿用原题选项顺序。
- 独立编写提示、分步解析、知识点总结和易错提醒。
- 不录入来源不明的整套题，不使用付费题库、教辅或商业试卷原文。
- 同一教材、年级、难度和题型内，题干与核心算式均通过自动去重检查。

## 后续增加题库

1. 在 `miniprogram/utils/question-bank-edition-data.js` 的年级知识蓝图中增加知识点或生成模型。
2. 保证每题具有 `answer`、`solution`、`knowledgeSummary`、`mistakeSummary` 和稳定 ID。
3. 更新 `question-bank-manifest.js` 的版本、日期和题量。
4. 运行 `npm test`，必须通过选项可作答、题干去重、算式去重、教材隔离、难度隔离和题池容量检查。
5. 在微信开发者工具中重新编译并走查摸底、每日练习、自主练习和错题解析。
