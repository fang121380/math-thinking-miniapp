# 梵数学迁移说明

## 在另一台电脑继续开发

1. 解压代码包到本地磁盘。
2. 安装 Node.js 和微信开发者工具。
3. 在微信开发者工具中选择“导入项目”，目录选解压后的 `math-thinking-miniapp`。
4. 使用自己的微信开发者工具账号登录；项目 AppID 在项目配置中确认，不要把 AppSecret 写入前端代码。
5. 如需运行本地测试，在项目根目录执行：

```powershell
node --test tests/*.test.js
```

## 项目结构

- `miniprogram/`：小程序页面、题库与自适应练习逻辑。
- `tests/`：题库、答题、错题与自适应逻辑测试。
- `docs/`：需求、题库扩充与测试说明。

## 会话记录

会话包内包含本次 Codex 会话的原始 JSONL 记录，供新电脑上的 Codex 读取背景、需求与历史操作。该记录是参考资料，不能保证在另一台设备上自动恢复为同一个 Codex 对话线程。
