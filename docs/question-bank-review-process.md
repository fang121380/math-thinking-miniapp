# 题库审校流程

本项目的每道题都保留考法参考区域、参考年份、考法标签和自动检查状态。它们说明的是原创改写时参考的公开考法，不表示转载原题。

运行 `node docs/tools/generate-question-review-report.js` 会生成每个“教材版本 x 年级”20道题的固定抽样清单，共960道。抽查时重点核对题意、答案、解析、难度、知识点、干扰项和教材匹配性；发现问题后应修正题目并重新运行 `npm test`。

自动检查覆盖题型、答案、解析、选项可作答性、唯一题干、教材年级隔离、题池容量和审校元数据。自动检查不能代替老师或教研人员对教学语言与难度梯度的复核。

人教版四年级上册首批 36 道思维代表题可运行 `npm run review:grade4-thinking` 生成专项复核队列。生成文件位于 `docs/qa/2026-09-20-grade4-thinking-review-queue.md`，默认全部为待复核，不能在实际教师或教研人员确认前改写为已审核。
