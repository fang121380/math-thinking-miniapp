## 已修复的问题

1. **章节 ID 混淆**：原四上“乘法估算”和四下“观察物体（二）”都使用 `rjb-g4-concept-02`。小学章节 ID 现包含册别，避免把不同章节归入同一个标识。题目 ID 和已保存答题记录的引用方式不变。
2. **错误的精确等式**：生成的除法估算解析原来可能将截到两位小数的商写在等号后。现在比较相邻整十数与除数相乘的结果，用整数乘法与距离判断解释答案。
3. **乘法估算解释不充分**：原来先说把乘数取整，却直接给出对精确积取整的结果，两者可能不一致。现在先展示成立的乘法等式，再说明取整规则。
4. **距离相等时题意不唯一**：对恰好位于两个候选整十/整百数中间的题目，明确按四舍五入取较大的数。
5. **观察方向不明确**：“首尾排成一排”无法排除前后遮挡。共享生成器现明确从左到右紧挨摆放、不叠放及观察方向。

估算和观察题修复位于共享四年级生成器，因此其他小学教材版本的对应题型也受益；教材来源标记只覆盖有记录的范围。题库版本已提升，以触发现有当日题组更新逻辑。
