# 小学游戏判定修复记录

日期：2026-09-20

## 用户报告

- “目标数挑战”把 `36 - 17 + 16 = 35` 判为错误，尽管算式成立且所有令牌都来自当前托盘。
- “规律侦探”显示 `22、26、36、46、?`，但仅提示观察相邻数字，未说明奇数位和偶数位要分开观察，导致题意不清。

## 原因与修复

- 目标数判定先要求玩家使用预设答案的令牌多重集，再检查等式。现改为先确认令牌均来自托盘、不重复且数量完整，再根据实际算式检查等式，因此所有数学上成立的完整排法都能通过。
- 四年级数列会放大数值，旧逻辑同时把具体规则覆盖为泛化说明。现在根据最终数列重新生成说明；隔项数列会明确提示“把奇数位和偶数位分开观察”，并说明两组的增量。
- 已保存的旧隔项数列如果仍是泛化提示，会在恢复时被质量校验拒绝并重新生成，不会继续显示旧问题。
- 36 道四年级思维题的重复学期、单元和能力字段改为统一生成，保持内容不变并释放主包空间。
