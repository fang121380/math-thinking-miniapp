# 小学游戏判定修复记录

日期：2026-09-20

## 用户报告

- “目标数挑战”把 `36 - 17 + 16 = 35` 判为错误，尽管算式成立且所有令牌都来自当前托盘。
- “规律侦探”显示 `22、26、36、46、?`，但仅提示观察相邻数字，未说明奇数位和偶数位要分开观察，导致题意不清。

## 原因与修复

- 目标数判定先要求玩家使用预设答案的令牌多重集，再检查等式。现改为先确认令牌均来自托盘、不重复且数量完整，再根据实际算式检查等式，因此所有数学上成立的完整排法都能通过。
- 四年级数列会放大数值，旧逻辑同时把具体规则覆盖为泛化说明。现在根据最终数列重新生成说明；隔项数列会明确提示“把奇数位和偶数位分开观察”，并说明两组的增量。
- 已保存的旧隔项数列如果仍是泛化提示，会在恢复时被质量校验拒绝并重新生成，不会继续显示旧问题。
- 36 道四年级思维题的重复学期、单元和能力字段改为统一生成，保持内容不变并释放主包空间。

## 手机复验后的追加修复

用户在手机上再次报告 `18、34、30、44、?` 的四个选项都无法完成。该题的正确答案和选项都是 42，但题目生成数据缺少 `choice` 模式：界面为了显示选项临时使用了选择题模式，提交逻辑却仍读取原数据，因此按“检查答案”时没有进入任何判定分支。首批回归只覆盖了生成答案和规则说明，没有调用页面的实际检查方法，导致漏测。

- 数列题现在显式生成 `mode: 'choice'`，质量校验会拒绝没有该模式的旧缓存题目并换新题。
- 页面提交依据实际渲染的选择题模式进入判定，即使遇到旧数据也能正确处理。
- 隔项数列不再使用易误解的“奇数位/偶数位”，而是直接显示“第1、3、5个数”和“第2、4个数”的具体数字及步长。
- 未提交选项使用中性黄色高亮，答对完成后改为绿色，避免把红色“已选中”误认为答错。
